# Flask Portfolio Website

## About

This project is a personal portfolio website developed using **Python Flask, HTML, and CSS**. It displays personal information, skills, projects, and contact details.

## Technologies Used

* Python
* Flask
* HTML
* CSS

## Features

* Personal information
* About Me section
* Skills section
* Projects section
* Contact form
* Flask routing
* Simple and responsive design

## Project Structure

```text
portfolio/
│
├── app.py
├── templates/
│   └── index.html
│
└── static/
    └── style.css
```

## How to Run

1. Open the project in VS Code.
2. Create and activate a virtual environment.
3. Install Flask:

```bash
pip install flask
```

4. Run the application:

```bash
python app.py
```

5. Open the following link in your browser:

```text
http://127.0.0.1:5000
```

## Objective

The objective of this project is to learn the basics of Flask routing, templates, HTML forms, and CSS styling while developing a simple real-world web application.
